# 제주 읍면동 소비 전환 진단표

관광객이 방문한 만큼 그 동네에서 소비가 일어나는지 제주 43개 읍면동을 비교한다.
공개 페이지: https://dark-ran.github.io/jeju-spend-conversion/

## 지표
전환 지수 = (읍면동 관광객 카드 소비 ÷ 방문객 수) ÷ 제주 전체 같은 값. 1.0이 제주 평균이다.

## 재현
제주관광빅데이터플랫폼(data.ijto.or.kr) 데이터 픽에서 CSV를 받아 `data/`에 아래 이름으로 넣고 `python3 -I build.py`를 실행한다.
파이썬 표준 라이브러리만 쓴다. 그림은 `figs.py`(matplotlib)로 만든다.

| 파일 | 플랫폼 데이터 |
|---|---|
| 읍면동방문.csv | 제주 지역별 방문객(읍면동), SKT |
| 소비.csv | 제주 지역별 소비, BC카드 |
| 읍면동도착.csv | 제주 지역별 차량 도착 수, 티맵 |
| 오름.csv, 곶자왈.csv | 오름별 차량 도착 수, 곶자왈별 도착수, 티맵 |
| 입도.csv | 월별 입도 관광객, 제주특별자치도관광협회 |
| 한라산.csv | 한라산 탐방객 |

## 한계
- 카드 소비는 전체 소비가 아니고, 방문은 읍면동별 30분 이상 체류 추정치다. 지수는 상대 비교용이다.
- 인과나 정책 효과를 뜻하지 않는다. 등급 기준 0.8은 작성자가 정한 값이다.
- 도착 데이터는 2026년 집계 로직이 바뀌어 오름 표시는 2025년 값만 쓴다.

출처: 제주관광공사 제주관광빅데이터플랫폼. 원본 CSV는 이 저장소에 넣지 않았다.
